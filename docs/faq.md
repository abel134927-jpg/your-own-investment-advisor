# FAQ

## 用量上限？會不會很快就把額度用完？

建議一週跑一次（各模組原本就是設計成「週報」）。Claude Pro / ChatGPT Plus 這種一般訂閱等級的用量額度，跑一次完整的四段流程（研究 → 草稿 → 紅隊 → 定稿）通常是夠用的。如果你想更頻繁地跑，或額度比較緊，可以只跑記帳流程（隨時可用，成本很低），把完整週報流程留到每週一次。

## 沒有 Chrome/Edge 怎麼辦？

不影響使用。系統設計成找不到瀏覽器就自動降級成只出 HTML、不出 PDF，exit code 仍然是成功，`final.md` 裡會註明降級原因。HTML 報告本身就是完整的，可以直接用任何瀏覽器打開閱讀或列印。想要 PDF 的話，之後安裝 Chrome 或 Edge 再重跑即可。

## 報告裡的數據是哪來的？

Agent（Claude 或 Codex）用自己內建的網頁搜尋能力（WebSearch）即時查資料，系統本身不呼叫任何需要 API key 的第三方數據服務。這代表資料品質取決於 agent 當下搜得到什麼——查不到的東西（例如某檔標的的即時價格、某季財報數字）一律會被明確標示為 `MISSING` 或 degraded，禁止用其他標的的數字推算或腦補填入。看到報告裡出現 degraded 標記是正常的資料品質揭露，不是系統故障。

## 能不能自動排程,每週自動幫我跑？

v1 是純手動——你想跑的時候對 agent 說觸發語（見 README「兩個模組」一節），它才會執行。本 repo 不內建排程機制。如果你想要自動化（例如每週一早上自動觸發），需要你自己接上你熟悉的排程工具（作業系統的排程器、CI、或其他自動化方案），本 repo 不提供也不支援這類整合。

## 能不能接更進階的量化數據層（排名、回測、因子模型之類的）？

系統設計上，紅隊與主筆的判斷把量化訊號當成**佐證與反證**，不能單獨變成買賣指令——這個原則不會因為你接了進階數據源而改變。如果你想自己接上市面上開源的量化研究 / 回測工具來強化證據品質，那是你自己的選配，本 repo 不打包、也不提供整合支援。另外要提醒：這類專案很多是 AGPL 一類的授權，使用前請自行確認授權條款是否符合你的使用情境（尤其是商用）。

## `examples/` 裡的報告是真的嗎？

不是。`examples/` 底下所有持倉、交易紀錄、研究內容、報告數字都是為了展示排版與流程而編造的**示範資料**，報告裡也都明確標註「示範資料」字樣。它不對應任何真實帳戶、真實市場狀況或真實投資建議，純粹是讓你在還沒建立自己的帳本之前，先看看系統跑起來長怎樣。
