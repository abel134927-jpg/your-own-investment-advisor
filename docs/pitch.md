# 屬於你自己的投資顧問 —— 分享給朋友的一頁介紹

嘿，這是我在用的一個小工具，覺得對你可能有用，花兩分鐘看一下。

## 痛點

自己做投資研究最麻煩的不是「找不到資料」，是每週要固定坐下來，把一堆分散的新聞、財報、估值數字整理成一個「現在到底該怎麼辦」的判斷；記帳也是，交易記到一半就懶得記了，最後連自己實際持倉是什麼都搞不清楚。這個 repo 就是把這兩件事包成一套流程，交給你原本就在用的 Claude 或 ChatGPT 桌面 agent 去跑，不用多裝任何東西、不用多付任何錢。

## 兩個模組分別解決什麼

- **AI 產業鏈週報**：每週幫你把一個產業（預設是 AI 產業鏈，但可以換成任何你關心的產業）的資本支出、供應鏈瓶頸、變現狀況、估值風險整理成一份帶熱力圖的報告，附一個先形成獨立空頭觀點、再回頭攻擊草稿的「紅隊」流程，判斷不會只有一種聲音。
- **Portfolio Weekly + 記帳**：把你自己的持倉、投資政策接進來，每週做一次顧問流程（持倉狀態、buy/sell 建議、風險檢查），外加隨時可以用講的記一筆交易——講完系統會列一張確認表給你看，你明確說「確認」它才會真的寫進帳本，不會自己亂動你的紀錄。

## 三步上手

1. 你原本應該已經有 Claude Pro 或 ChatGPT Plus 其中一個訂閱，裝好對應的桌面版 agent（Claude 桌面版 / Claude Code，或 Codex 桌面版 / CLI）就行。
2. 把這個 repo `git clone` 下來，或直接下載 zip 解壓縮。
3. 打開資料夾，對 agent 說一句「讀 README 幫我完成安裝」，剩下的環境檢查、安裝步驟它會自己讀 `AGENTS.md` / `skills/*/SKILL.md` 走完。

## 成本

不需要額外付費。只要你已經有 $20/月等級的 Claude Pro 或 ChatGPT Plus 訂閱，這個系統就是免費用你原本的額度跑，沒有 API key、沒有額外訂閱、沒有伺服器費用。

## 隱私與免責

你的真實持倉、交易紀錄、投資政策全部只存在你自己的電腦上，這個 repo 的 `.gitignore` 已經把這些目錄排除，不會被提交、不會上傳到任何地方。

**這東西產出的所有報告，僅供研究與教育用途，不構成投資建議；最終決策與下單永遠由你自己完成。** 系統不會自動下單，寫帳本一定要你本人明確確認過才會發生。想看更完整的說明可以看 [README](../README.md) 跟 [FAQ](faq.md)。
